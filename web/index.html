Display and sensor

Wi-Fi networks

The monitor joins the strongest saved network in range, and works without Wi-Fi elsewhere.

    To set up Wi-Fi from a phone instead: on the monitor, hold D1 for the settings and choose Set up Wi-Fi.

    Maintenance
    Clean the fan

    Full speed for 10 s; readings pause for about 40 s. The sensor also does this weekly by itself.

    Calibrate CO₂

    Only after at least 3 minutes in fresh outdoor air, with the reference value of that air.

    ppm
    Restart

    Firmware update

    Upload a firmware.bin (not firmware.factory.bin). If the new firmware can't rejoin Wi-Fi within 5 minutes, the monitor goes back to the current one.
